# Pantallazo de mi CV
El CV está diseñado en PHP utilizando Tailwind CSS para la parte visual. La imagen principal muestra la estructura del diseño que utilizas en la interfaz web, mientras que en el HTML (la imagen de "Descarga") corresponde al formato generado para ser descargado, en donde los estilos de Tailwind no se aplican debido a que utilizo dompdf para la generación del PDF, y este no soporta Tailwind CSS directamente.
